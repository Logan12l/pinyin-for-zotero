说明：content/data.js 中的汉字读音表（ZPS_TABLE_A / ZPS_TABLE_B）与
      姓氏读音表（ZPS_SURNAMES / ZPS_COMPOUND_SURNAMES）由 node-pinyin 的
      发行数据生成（生成时使用的是同版本数据的本地副本，取自 Better BibTeX
      所打包的同一份 node-pinyin 数据；Better BibTeX 亦为 MIT 许可）。
      本插件未包含 node-pinyin 的运行时代码，只使用了其数据。
      ZPS_SURNAME_EXTRA 中的少量姓氏修正由本插件作者依据常见姓氏读音编写。

2. 关于 Zotero 与 citeproc-js
------------------------------------------------------------
Zotero 客户端源码以 GNU AGPL-3.0 发布
（见 https://www.zotero.org/support/licensing）；
其内置的 citeproc-js 为 CPAL-1.0 / AGPL-3.0 双许可。

本插件是独立的第三方插件：不包含、也不分发 Zotero 或 citeproc-js 的源代码，
仅通过 Zotero 的 JavaScript API 与其交互（含为修正排序而包装公开可达的
排序函数）。插件采用与 Zotero 相同的 AGPL-3.0 许可。
